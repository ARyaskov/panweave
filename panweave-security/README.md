# panweave-security

Panweave Zigbee stack: CCM*, AES-MMO, key hierarchy, frame security and Trust Center policy.

Part of [Panweave](https://github.com/ARyaskov/panweave), a workspace of
crates: `panweave` is the facade to start from; the architecture, the
specification map, the security and storage models, the conformance
inventory and the integration guides live in the repository's `docs/`.

Panweave is an independent implementation from the published
specifications; it is not affiliated with, endorsed by, or certified by
the Connectivity Standards Alliance.
